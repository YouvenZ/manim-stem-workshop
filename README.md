# Animate to Educate — Manim for STEM teachers

A hands-on workshop for teachers of **mathematics, physics, biology, programming and
bioinformatics**: learn [Manim](https://www.manim.community/) (the Python animation engine
behind 3Blue1Brown) and build your own classroom videos.

- 🌐 **Website** (gallery: every video next to its source code): `https://<you>.github.io/manim-stem-workshop/`
- 🎞️ **Slides** (reveal.js, with the videos and live demos built in): `https://<you>.github.io/manim-stem-workshop/slides/`

## Quick start on Windows (`run.ps1`)

```powershell
.\run.ps1 setup                 # create the conda env (first time only)
.\run.ps1 preview -Scene 05     # render one scene fast and open it
.\run.ps1 render                # render all scenes into docs/ (-Quality h for 1080p, -Only 03 for one)
.\run.ps1 serve                 # website at http://localhost:8000   (slides: .\run.ps1 slides)
.\run.ps1 publish -RepoUrl https://github.com/<you>/manim-stem-workshop
```

If PowerShell says scripts are disabled, run it as
`powershell -ExecutionPolicy Bypass -File .\run.ps1 serve`.

## 1. Set up the Python environment

### Option A — conda (recommended)

```bash
conda env create -f environment.yml
conda activate manim-workshop
manim --version        # Manim Community v0.22.x
```

### Option B — pip / venv

Requires [FFmpeg](https://ffmpeg.org/download.html) on your `PATH` (and on Linux
`sudo apt install libcairo2-dev libpango1.0-dev`).

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
```

### LaTeX (needed for `MathTex`)

- Windows: [MiKTeX](https://miktex.org/download) (allow "install missing packages on the fly")
- macOS: [MacTeX](https://www.tug.org/mactex/)
- Linux: `sudo apt install texlive-latex-extra texlive-fonts-extra dvisvgm`

## 2. Render

```bash
# one scene, preview, low quality (fast iteration)
manim -pql scenes/01_pythagoras.py Pythagoras

# everything -> docs/videos, docs/posters, docs/code (720p30, ~5 min)
python scripts/render_all.py
python scripts/render_all.py -q h          # 1080p60
python scripts/render_all.py --only 05     # just one scene
```

Run commands from the repository root so `manim.cfg` is picked up.

## 3. Preview the website and slides locally

```bash
python -m http.server -d docs 8000
```

Open <http://localhost:8000> (website) and <http://localhost:8000/slides/> (slides).
Use a local server rather than double-clicking `index.html`: the gallery loads
the source code with `fetch`, which browsers block for `file://` pages.

Slide keys: `→`/`←` navigate, `↓` enters the gallery, `Esc` overview, `S` speaker notes,
`F` full screen, `Alt+click` zoom.

## 4. Publish on GitHub (website + slides)

1. **Create an empty repository** on GitHub named `manim-stem-workshop`
   (no README / licence, so the first push is clean).
2. **Push** from the project folder:

   ```bash
   git init -b main
   git add .
   git commit -m "Manim for STEM teachers workshop"
   git remote add origin https://github.com/<you>/manim-stem-workshop.git
   git push -u origin main
   ```

3. **Turn on Pages:** on GitHub, open *Settings → Pages → Build and deployment →
   Source* and choose **GitHub Actions**.
4. The workflow `.github/workflows/pages.yml` runs on every push to `main`
   (watch it under the *Actions* tab). After about a minute the site is at

   - `https://<you>.github.io/manim-stem-workshop/`
   - `https://<you>.github.io/manim-stem-workshop/slides/`

5. **Set your repository URL** in `docs/assets/js/examples.js` (`window.REPO_URL`) so
   the "GitHub ↗" buttons and the clone commands point to your fork, then commit and push again.

**Updating:** edit a scene → `python scripts/render_all.py --only 03` → `git add . && git commit -m "..." && git push`.
The videos are committed to the repo (~1–4 MB each at 720p), so Pages needs no build step.

> Alternative without Actions: *Settings → Pages → Source: Deploy from a branch → `main` / `/docs`*.
> The `docs/.nojekyll` file is already there so GitHub serves the folder as-is.

## 5. Running the workshop

Suggested 3-hour flow (also on the website):

| Time | Block |
|---|---|
| 0:00 | Why animate? What is Manim? Gallery tour |
| 0:20 | Setup & “Hello, Manim” (predict → watch) |
| 0:45 | Core toolkit: mobjects, animations, rate functions, `ValueTracker` (live demos in the slides) |
| 1:30 | Break — start a render in the background |
| 1:45 | Hands-on: tweak a gallery scene, then `exercises/ex1_tangent_line.py`, then `ex2_your_concept.py` |
| 2:40 | Teaching principles, embedding, publishing, show & tell |

Ask participants to install the environment **before** the session, and to run
`manim -pql scenes/00_hello_manim.py HelloManim` as a check.
