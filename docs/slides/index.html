Motivation

Why animate?

🎯

Show change

Derivatives, waves, populations, algorithms… STEM is about processes. Static figures freeze them; animation shows the “how”.

🧠

Lower the load

Build a picture step by step, one idea at a time, instead of one dense figure. Students follow attention cues (colour, motion).

🔁

Reproducible

Animations are code: change one parameter, re-render, version with git, share with colleagues.

Mayer's multimedia principles: segmenting, signalling, coherence. Animation is not automatically better — it is better when it shows a process that a static image cannot.
The tool

What is Manim?

  • A Python library for precise, programmatic animations
  • Created by Grant Sanderson for 3Blue1Brown
  • Manim Community (ManimCE): the documented, stable fork we use today
  • Native LaTeX, graphs, coordinate systems, 3D, updaters
  • Output: MP4, GIF, PNG — usable in any LMS, slides or YouTube

Your first scene · predict before you watch

Hello, Manim


from manim import *

class HelloManim(Scene):
    def construct(self):
        circle = Circle(radius=1.5, color="#4F9DFF", fill_opacity=0.5)
        square = Square(side_length=3, color="#FF8A3D", fill_opacity=0.5)
        label = Text("Hello, Manim!").next_to(circle, DOWN)

        self.play(Create(circle), Write(label))
        self.wait(0.5)
        self.play(Transform(circle, square))
        self.play(circle.animate.rotate(PI / 4).set_color("#3DDC97"))
        self.play(Indicate(label, color="#FFD166"))

manim -pql scenes/00_hello_manim.py HelloManim

Step through the highlighted lines and ask the room to describe what will appear. Then reveal the video.

Interactive · timing matters

Rate functions

Every animation maps time t∈[0,1] to progress. The default is smooth.


self.play(dot.animate.shift(RIGHT * 6),
          rate_func=there_and_back,
          run_time=2)

Click a function → the dot moves with it, and its graph is drawn.

Pacing is pedagogy: rush_from for something that "snaps" into place, linear for clocks (time must flow uniformly), smooth almost everywhere else.
Interactive · the most useful idea in Manim

ValueTracker + always_redraw


x = ValueTracker(-2)
tangent = always_redraw(lambda: axes.get_secant_slope_group(
    x.get_value(), graph, dx=0.001, secant_line_length=4))
dot = always_redraw(lambda: Dot(axes.i2gp(x.get_value(), graph)))
slope = always_redraw(lambda: DecimalNumber(df(x.get_value())))
self.add(tangent, dot, slope)
self.play(x.animate.set_value(2), run_time=6)

A ValueTracker holds one number. Anything built with always_redraw is rebuilt every frame from it.

Teaching with animations

Design principles

  • One idea per scene — 20–90 s beats, not 10-minute films
  • Predict → watch → explain: pause before the reveal
  • Colour = meaning, used consistently (prey is always green)
  • Leave time: self.wait() after every key change
  • Link representations: same clock for pendulum & phase space
  • Fewer words on screen, more narration (yours!)
  • Accessibility: high contrast, captions, colour-blind-safe pairs
  • Let students code a parameter change — they own the model
Using your videos

Where do the videos go?

Slides

<video data-autoplay> in reveal.js (like this deck), or insert MP4 in PowerPoint / Keynote.

LMS

Upload MP4 to Moodle / Canvas; GIF where video is blocked.

Web

GitHub Pages site with gallery + code (this repo’s docs/).

Paper

manim -s last frame → worksheet figures.

Bonus: manim-slides turns a Manim scene itself into a clickable presentation.
