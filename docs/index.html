Get started

Everything runs locally on Windows, macOS or Linux.

Get the workshop files

Clone the repository (or download it as a ZIP from GitHub).

$ git clone https://github.com/YouvenZ/manim-stem-workshop.git
$ cd manim-stem-workshop

Create the Python environment

Conda is the easiest route: it ships Manim, its Cairo/Pango libraries and FFmpeg.

$ conda env create -f environment.yml
$ conda activate manim-workshop
$ manim --version            # Manim Community v0.22.x
# needs FFmpeg on your PATH (and on Linux: libcairo2-dev libpango1.0-dev)
$ python -m venv .venv
$ .venv\Scripts\activate      # macOS/Linux: source .venv/bin/activate
$ pip install -r requirements.txt

Install LaTeX (for equations)

MathTex needs a LaTeX distribution: MiKTeX (Windows), MacTeX (macOS) or sudo apt install texlive-latex-extra texlive-fonts-extra dvisvgm (Linux). Scenes that only use Text work without it.

Render your first scene

-p previews when done, -ql renders fast at 480p while you iterate.

$ manim -pql scenes/00_hello_manim.py HelloManim
$ python scripts/render_all.py   # all scenes -> docs/videos/

Workshop agenda (3 hours)

A suggested flow; every block maps to a section of the slides.

0:00 – 0:20

Why animate? · What is Manim?

Dynamic representations, cognitive load, and a tour of the gallery.

0:20 – 0:45

Setup & “Hello, Manim”

Environment, CLI flags, first scene, the Scene → Mobject → Animation model.

0:45 – 1:30

Core toolkit

Axes & graphs, MathTex, ValueTracker + updaters, colours and layout.

1:30 – 1:45

Break ☕

Render something in the background!

1:45 – 2:40

Hands-on by discipline

Pick an example, modify it, then build your own from the exercise templates.

2:40 – 3:00

Share & publish

Pedagogy tips, embedding in slides/LMS, publishing on GitHub Pages, show & tell.
